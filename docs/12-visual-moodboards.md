## Moodboard A — Human Stories

### Atmosféra
Teplý papír, dokumentární světlo, „časopisový“ klid. Portrét je hlavní hrdina; typografie slouží hlasu člověka.

### Palette swatches
1. `#F3EDE4` Paper  
2. `#1A2330` Ink  
3. `#2F6F6A` Teal  
4. `#C9854A` Amber  
5. `#D9D0C4` Line  
6. `#8B7355` Archive brown (secondary)

### Type pairing
| Role | Návrh rodiny | Spec |
| --- | --- | --- |
| Display / citát | Fraunces nebo Source Serif 4 | 42–72 px desktop, optical size |
| Jméno | stejný serif, medium | tracking mírně otevřený |
| UI / nav | IBM Plex Sans / Geist | 14–16 px |
| Meta (město, rok) | Plex Sans | uppercase 11–12 px, letter-spacing 0.06em |

### Photo treatment
- Současné: natural color, jemný warm lift shadows, grain 3–6 %
- Archiv: soft sepia/olive duotone, vignette jemná
- Žádné heavy HDR, žádné neon overlays
- Oči/obličej vždy ostřejší než pozadí (portrait priority)

### Kompozice tile (6 polí moodboardu)
1. Candid portrait (nádraží / okno vlaku) — `ILLUSTRATIVE-portrait-candid.jpg`  
2. Type + palette — `ILLUSTRATIVE-type-palette.jpg`  
3. Departure dawn — `assets/ai-placeholder-ILLUSTRATIVE-departure-dawn.jpg`  
4. Detail rukou / pas / jízdenka (doplnit)  
5. Citát na papíře (typografický mock)  
6. Skupinový „kitchen of flatshare“ (doplnit reálnou foto)

### UI chrome
Bez karet ve hero. Sekundární příběhy: text+obrázek full-bleed střídavě L/R, ne card grid. Pokud grid, jen pro výběr (interakce).

Noční / dusk Evropa, světelné trasy, pocit rychlosti bez chaosu. Graphic systems > faces (tváře sekundární).

### Palette swatches

2. `#3BB8B0` Signal teal  
3. `#E0A04A` Amber spark  
4. `#9AA7B8` Fog  
5. `#E8E2D8` Paper insert  
6. `#13233A` Panel

### Type pairing
| Role | Návrh | Spec |
| --- | --- | --- |
| Display | Syne / Space Grotesk | bold, tight leading |
| Mono / coords | IBM Plex Mono | trasy, km, kódy měst |
| Body | Plex Sans | na paper insertech |

### Photo / graphic treatment
- Motion blur travel stills — `ILLUSTRATIVE-motion-travel.jpg`  
- Network map still — `ILLUSTRATIVE-europe-network.jpg` + `ai-placeholder-ILLUSTRATIVE-map-europe-routes.jpg`  
- City night — `ai-placeholder-ILLUSTRATIVE-city-night-europe.jpg`  
- Line weight 1–2 px; nodes 4–8 px; pulse opacity ≤ 40 %

### Kompozice tile
1. Network Europe  
2. Train window blur  
3. City night routes  
4. Kinetic type specimen („POHYB“)  
5. Node detail Praha–Berlin (illustrative)

### Riziko looku
Nepřepálit glow / bloom — vypadá „AI dark mode default“. Preferovat matné navy a čisté čáry.

## Moodboard C — Then / Now / Next

### Atmosféra
Výstavní katalog: levá strana „archiv“, pravá „současnost“, dole „náznak budoucna“. Klid, srovnání, srozumitelnost.

### Palette swatches
1. `#F0EBE3` Paper  
2. `#1E1E1C` Ink  
3. `#6B6A4E` Archive olive  
4. `#4A5E73` Now blue-gray  
5. `#2E5C4F` Next green-ink  
6. `#C4B8A5` Rule line

### Type pairing
| Era | Type | Poznámka |
| --- | --- | --- |
| Then | Source Serif / podobný | mírně vyšší kontrast |
| Now | Plex Sans | neutrální |
| Next | Plex Sans light + wide tracking | bez futuristických fontů |

### Photo treatment
- Then: faded 90s grade, soft focus edges — levá půlka `ILLUSTRATIVE-then-now-split.jpg`  
- Now: crisp, cooler WB  
- Next: abstraktní tvary / negativní prostor, ne fake UI  
- Wipe / diagonal jako art motif (ne jako překážka čitelnosti textu)

### Kompozice tile
1. Split then/now hero  
2. Archive corridor detail  
3. Contemporary atrium  
4. Timeline rule specimen  
5. Dual caption typography  
6. Next: outline map / open horizon (doplnit)
