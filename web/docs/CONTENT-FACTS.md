## 4. Příběhy
- Souhlasy se zveřejněním skutečných příběhů nebyly k implementaci dodány. **Přednost mají skutečné příběhy** z dzs.cz (články o účastnících, magazín Mozaika). Každý má `status: "verified"`, odkaz na zdroj a skutečné jméno a destinaci podle zdroje. Citace se nesmí upravovat.
- Modelové příběhy jsou v `src/content/stories.ts` (8 typů mobilit) a slouží do doby, než je nahradí skutečné. Každý má viditelný štítek „Modelový příběh – ilustrační“ a smyšlené jméno bez vazby na reálné osoby.

## 5. Hero video – shot list (30–45 s, bez mluveného slova, hudba bez autorských nároků)
1. Detail: ruka zapíná zip kufru (ráno, okno) 2. Praha hl. n., odjezdová tabule 3. Vlak se rozjíždí, pohled z okna – krajina 4. Příjezd: nové město, první krok z nádraží 5. Kampus, chodba, knihovna 6. Kolej – společná kuchyně, smích, různé jazyky 7. Večerní ulice, skupina přátel 8. Zpáteční cesta, pohled z okna, úsměv 9. Poslední záběr: stejné okno jako v úvodu – jiný člověk.
**Prototyp (teď):** placeholder film se sestaví z vybraných klipů Pexels (`src/content/media.json`, `npm run media:fetch && npm run media:hero`) a má štítek „Ilustrační video“. **Před publikací** se nahradí skutečným materiálem (archiv DZS, EK Audiovisual Service, vlastní natáčení).
